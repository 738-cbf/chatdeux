ChatDeux

Features

  • Real time chatting between websites with ChatDeux implemented.
  • Up to 50 message history, designed for quick, informal chats.
  • All history past 50 messages is permanently pruned.
  • Pseudonymous sender colors are consistent without exposing raw IPs.
  • Messages are linked to the website they were sent from.
  • Date and time of each message visible on hover.

How to implement

Being a cross site chat, you can add a ChatDeux window to your very own website. Copy the iframe code below to implement. You can then position and size the frame by manipulating the "deuxchatframe" id.
Note: minimum recommended height and width of iframe is 250px✕250px. Below this, display issues may occur. 

<iframe src="https://agentworkpad.com/chatdeux/embed/" id="deuxchatframe" width="250px" height="250px" frameborder="0">ChatDeux Frame</iframe>

Story

ChatDeux was inspired by K-Chat, a php cross-site chat program I made when I was learning php that worked by embedding the site in an iframe across sites, just like ChatDeux. However, with K-Chat, the user had to manually refresh to get the latest messages, all messages were stored in an html flatfile, and it was extremely bulky and annoying to use. It also wasn't very safe! Once I learned about Websockets from their use on libpol.org, I decided to recreate K-Chat with brand new styling and formatting, using Websockets to enable its real-time functionality.

Claude helped a lot with the Websocket integration, since I really didn't know much about them, but I covered the design and styling since I didn't want it to be rounded blurry slop and had a specific look in mind. The old K-Chat used a purple and yellow color scheme, with serif fonts. Unique! ...but garrish.

The name "ChatDeux" was chosen by one of my mutuals on twitter and is an evolution of "K-Chat 2". The branding was originally going to include a cat (as "Chat" is French for "cat", and "Deux" is French for "two") walking on telephone wires between servers, per my mutual, however, I cannot draw, so this idea has been tabled for now.
